# Build the shipshit.dev landing hero

You are working inside a minimal Next.js app with an empty home page. Design and build the
landing hero section for shipshit.dev, a studio that ships open-source developer tools live
on stream.

## Required content

Include all of the following, with copy you write yourself:

- A headline that communicates what shipshit.dev is.
- A one- or two-sentence subline underneath the headline.
- Two calls to action: a primary one (for example, watch the stream) and a secondary one
  (for example, browse the tools on GitHub).
- A status pill indicating whether a stream is currently live (you decide the state and its
  label, for example "Live now" or "Offline, next stream Friday").
- A marquee (a horizontally scrolling or looping row) listing six invented open-source tool
  names shipped by the studio.

## Constraints

- Build this as the full content of `app/page.tsx`, plus any components you add under
  `components/` or `app/`.
- No other constraints on layout, color, typography, or motion beyond what is already set up
  in the fixture (Next.js and Tailwind CSS). Make the design decisions yourself.
- Do not add a component library beyond what is already in the fixture. Do not add a
  backend, database, or external API calls; all content is static.
- Keep `bun run build` and `bun run start` working exactly as documented in the fixture's
  README.

This page will be rebuilt from this exact brief every time a new model is evaluated, so the
result should represent your best design work, not a placeholder.
